6 JavaScript функций

Функции:

  1. percentage(total, percent) - вычисляет проценты
  2. contains(str, subStr) - проверяет наличие подстроки
  3. toggle(value) - возвращает обратное булево значение
  4. getKeys(obj) - возвращает ключи объекта через запятую
  5. getLength(array) - возвращает количество элементов в массиве
  6. logElements(array) - выводит каждый элемент массива в консоль
